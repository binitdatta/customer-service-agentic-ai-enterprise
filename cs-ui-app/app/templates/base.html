What this app is all about

Learn the concepts, then see them running for real: secured, tool-driven, policy-governed.

Design goal: reference implementation + training lab

1) Generative AI

Concept
  • Turns natural language into structured outputs
  • Summarizes, extracts entities, drafts responses
  • Works best with grounding + policies

2) AI Agents

Behavior
  • Plans steps to solve a user goal
  • Uses tools (APIs/DB) to fetch facts
  • Asks clarifying questions when needed

3) Agentic AI

Execution
  • Multi-step workflows with state + memory
  • Guardrails for safe actions (policy checks)
  • Auditable outcomes (tickets + logs)

4) LangChain

Framework
  • Prompting + structured outputs
  • Tool calling patterns
  • RAG (optional) for policies + knowledge

5) LangGraph

Orchestration
  • Deterministic workflow graphs
  • Retries, branching, state transitions
  • Human-in-the-loop checkpoints

6) Keycloak

Security
  • OAuth2/OIDC authentication
  • Scopes/roles for action authorization
  • Token-based service-to-service security

7) MySQL 8 DB

Data
  • Orders, addresses, shipments, tickets
  • Seed data for repeatable demos
  • Reliable source of truth for workflows

8) Orders REST API App

Service
  • CRUD + status + address updates
  • Replacement + cancellation endpoints
  • Protected as Resource Server

9) Workflow App (LangGraph)

Orchestrator
  • Triage + plan + execute actions
  • Policy checks + approvals
  • Protected as Resource Server

10) UI App (Chat + Learning)

Experience
  • Human-friendly chat + guided flows
  • Concept pages (LangChain/LangGraph)
  • Login/logout + user context

How Agentic AI connects to the enterprise

This app is designed to mirror real enterprise patterns: identity, APIs, data, workflows, observability, and governance.

Identity & Access
  • Keycloak as IdP (OIDC)
  • Scopes/roles per action (replace, cancel, refund)
  • Service-to-service tokens for APIs
Systems of Record
  • Orders / shipping / inventory services
  • MySQL as demo store (mirrors production SoR)
  • Optional: CRM / ERP / WMS integrations
Operations & Governance
  • Correlation IDs across hops
  • Audit logs + ticketing trail
  • Policy rules to prevent unsafe actions
Human-in-the-loop
  • Clarifying question when required
  • Approval gates for high-risk actions
  • Customer-ready responses every time
